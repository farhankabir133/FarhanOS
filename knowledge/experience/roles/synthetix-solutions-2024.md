# Senior AI Developer — Synthetix Solutions (2024)

## Overview
Senior AI Developer at Synthetix Solutions, building production NLP and CV systems for real-time candidate evaluation.

## Responsibilities
- Architect and deploy AI systems in production
- Integrate NLP and computer vision modalities
- Build real-time inference pipelines
- Deploy and monitor models in production

## Business Impact
- Enabled real-time technical candidate evaluation at scale
- Reduced manual screening time significantly
- Improved hiring quality through data-driven evaluation

## Technologies Used
- React, Node.js, Express, Python
- MediaPipe, Wav2Vec, BERT
- Prometheus, Grafana, TensorFlow
- Docker, Redis, PostgreSQL

## Engineering Contributions
- Real-time NLP+CV fusion for candidate scoring
- Built inference optimization and batching layers
- Designed monitoring dashboards with Prometheus/Grafana

## Challenges
- Real-time performance with multiple modalities
- Monitoring and observability for ML models in production
- Scaling inference during peak evaluation periods

## Key Projects
- SafeSide Predictor — competency-based candidate assessment
- OMNIVA AI — enterprise LLM monitoring observability

## Lessons Learned
- Production ML requires monitoring from day one
- Multi-modal fusion demands careful latency optimization
- Observability frameworks must be designed alongside the model
