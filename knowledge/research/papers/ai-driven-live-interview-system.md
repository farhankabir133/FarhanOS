# AI-Driven Live Interview System — IEEE ICCIT 2025

## Objective
Design and evaluate a real-time automated candidate evaluation system combining NLP and computer vision during live interviews.

## Methods / Innovation
- Wav2Vec 2.0 for audio feature extraction and speech analysis
- BERT for textual response understanding
- MediaPipe for posture and facial expression tracking
- Fusion layer integrating acoustic, textual, and visual signals

## Dataset
- Curated interview transcripts and video recordings
- Human-annotated candidate performance scores

## Pipeline
1. Real-time video and audio capture
2. Wav2Vec + BERT + MediaPipe feature extraction
3. Multimodal fusion and scoring
4. Feedback and evaluation report generation

## Key Results
- Improved evaluation consistency vs single-modal systems
- Real-time inference with acceptable latency
- Strong correlation with human evaluator scores
